# Changelog

## 0.1.0 — 2026-10-25

- LAN HTTPS/WebSocket pairing with a desktop QR code, reconnects and one phone per session.
- Absolute phone touchpad with center guides, quadrant lines, corner labels and a position marker.
- Windows transparent, click-through, always-on-top red pointer with an approximately 500 ms fading trail.
- Foreground presentation previous/next commands, calibration, sensitivity and axis reversal.
- Feature-detected orientation, relative sensor and gravity-tilt fallback with first-order low-pass filtering.
- Permission and event diagnostics, with a retained last explicit authorization result.
- Windows launcher, verified mkcert setup, certificate guidance and private-subnet firewall helper.
- User reports: iPhone works (model/OS/browser unspecified), Huawei Mate X5 motion works, Huawei Pura X touch works while motion reports `NotAllowedError`.

Based on SilentTiger/laser-pen at `9694f27b846cd1baff527be2f9d14fdf86234854`; the original MIT-licensed canvas drawing core is retained.
